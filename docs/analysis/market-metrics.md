# 시장 지표

지표는 이해 가능한 단순 통계부터 시작한다.

## 시장 대표 변화

FC온라인에는 전체 유통량과 거래량을 알 수 없는 카드가 많기 때문에 가격 가중 시장지수는 사용하지 않는다.
PoC는 대표 카드의 일별 수익률 중앙값을 우선 사용한다.

- `market_return(t) = median(card_return_i(t))`

이를 기준값 100에서 누적해 시장지수를 만든다.
중앙값은 한두 개 초고가 카드의 극단적인 가격 변화가 전체 시장을 지배하는 문제를 줄인다.

## 상승 종목 비율

`breadth`는 해당 기간 가격이 상승한 카드의 비율이다.
시장지수가 상승해도 breadth가 낮으면 일부 카드만 시장을 끌어올리고 있을 수 있다.

## 상대강도

선수군 변화는 전체 시장과 비교한다.

- `relative_strength = cohort_return - market_return`

예를 들어 시장이 10% 오르고 핵심 선수군이 15% 올랐다면 상대강도는 +5%p다.
이 값은 명목 인플레이션과 개별 선수군 강세를 분리하는 데 사용한다.

## 분산도

시장 내부의 움직임이 얼마나 갈라지는지 확인한다.
초기에는 표준편차보다 이상치에 덜 민감한 Interquartile Range 또는 Median Absolute Deviation을 우선 검토한다.
불특정 공급 충격에서 다음 구조를 잡는 것이 목표다.

```text
시장 전체            +2%
직접 공급 고가군     -30%
비노출 희소군        +18%

시장 내부 분산 급증
```

## 이상징후

PoC는 원인을 모르는 상황에서도 가격 이상을 표시할 수 있어야 한다.
예를 들어 특정 cohort가 평소 변동 범위를 크게 벗어나면 다음 상태를 만든다.

```text
UNKNOWN_SHOCK
cohort: HIGH_END
detected_at: 2026-09-17 12:40 KST
direction: DOWN
severity: EXTREME
```

후속 공지가 확인되면 원인을 연결한다.
기존 관측값은 수정하지 않는다.
