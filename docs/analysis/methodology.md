# 분석 방법

PoC는 이해하기 어려운 모델보다 검증 가능한 통계를 사용한다.
초기 분석에 필요한 개념은 다음 정도다.

- 가격 변화율
- 중앙값
- 백분위
- IQR
- MAD
- 상승 종목 비율
- 상대강도
- 이동 통계
- 이벤트 전후 비교

회귀분석이나 머신러닝은 PoC 필수요건이 아니다.

## 이벤트 전후 분석

이벤트마다 다음 window를 계산할 수 있다.

- D-7
- D-3
- D-1
- D
- D+1
- D+3
- D+7

원본 가격의 granularity가 더 세밀하면 시간 단위 분석을 추가한다.
원본이 일 단위라면 인위적으로 시간 단위 값을 만들지 않는다.

## 비교군

직접 노출군의 변화만 보면 전체 시장 움직임과 구분하기 어렵다.
가능하면 다음 조건이 비슷한 비노출 카드를 comparison group으로 사용한다.

- 가격대
- 포지션
- 강화단계
- OVR
- 급여
- 시장 사용량

PoC는 완전한 인과추론을 목표로 하지 않는다.
비교군 결과를 사용하더라도 "영향을 입증했다"가 아니라 "시장 대비 차이가 관측됐다"고 표현한다.
