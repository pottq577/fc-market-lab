# 과거 가격 데이터 확보 Gate

PoC 전체에서 가장 먼저 통과해야 하는 단계다.

## Gate 0 성공 조건

다음 조건을 모두 충족해야 한다.

- 인기 선수 20~30명의 identity를 선정할 수 있다
- 각 선수의 주요 클래스 목록을 확보한다
- 주요 강화단계의 365일 가격값을 확보한다
- timestamp와 가격값을 기계 처리할 수 있다
- 동일 작업을 재현할 수 있다
- 데이터 취득 방식이 이용 조건에 부합한다
- 가격이 기준가인지 실거래 데이터인지 구분한다

하나라도 충족하지 못하면 분석 개발보다 데이터 확보 전략을 먼저 수정한다.
