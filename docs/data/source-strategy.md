# 데이터 출처와 수집 방법

데이터는 공식 API, 공식 공개 페이지, 수동 annotation, 검증된 외부 dataset을 구분한다.

## NEXON Open API

FC온라인 공식 Open API는 현재 계정, 매치, 랭커, 메타데이터, 이미지 영역을 제공한다.
공식 페이지는 API를 통해 수집한 데이터에 30일 이내 갱신 의무가 있다고 고지한다.
Open API는 다음 데이터에 우선 사용한다.

- 선수 메타데이터
- 랭커 관련 데이터
- 매치 정보
- 공식 ID 매핑
- 이미지와 season metadata

유저 거래내역 API는 본인 조회만 가능하도록 변경됐기 때문에 전체 이적시장 데이터 소스로 사용할 수 없다.

## 공식 데이터센터

선수 상세 페이지는 현재 가격과 7일, 30일, 90일, 180일, 365일 시세 선택지를 제공한다.
상위 랭커의 전일 플레이 기록도 함께 제공한다.
데일리차트는 전일 기준 데이터와 팀컬러, 포지션, 클래스 사용 정보를 제공한다.
PoC에서 필요한 정보는 다음과 같다.

- 365일 가격 시계열
- 현재가
- 세부 능력치
- 급여
- 랭커 실사용 데이터
- 팀컬러 이용 데이터

### 가격 그래프 수집의 제약

공개 GitHub 프로젝트 `JCH1231/fifa-simulation-data`에는 모바일 데이터센터의 `PlayerPriceGraph` 응답에서 `chartData`를 파싱하는 구현이 존재한다.
기술적으로 기계 판독 가능한 시계열이 존재한다는 참고 자료로 사용할 수 있다.
그러나 이를 PoC의 자동 수집 경로로 바로 채택하지 않는다.
NEXON Open API 이용약관에는 허가된 API 이용 외에 넥슨 게임·서비스·웹사이트를 대상으로 데이터 마이닝, 스크래핑, 크롤링 또는 자동화된 질의를 수행하지 않는다는 조항이 있다.
따라서 가격 시계열 확보는 별도 Gate 0를 통과해야 한다.

가능한 순서는 다음과 같다.

1. 공식적으로 허용되는 가격 데이터 인터페이스가 있는지 확인한다
2. Open API 또는 공식 허용 방식으로 365일 시계열을 받을 수 있는지 확인한다
3. 이용 가능한 제3자 공개 dataset의 라이선스와 출처를 확인한다
4. 필요하면 넥슨에 데이터 활용 범위를 문의한다
5. 허용 경로가 확인된 뒤 자동 수집을 구현한다

기술적으로 접근 가능하다는 사실과 이용 가능한 데이터라는 판단을 분리한다.

## 공식 공지사항

공지는 과거 사건을 재구성하는 핵심 source다.
수집 대상은 다음과 같다.

- 점검
- 업데이트
- 개발자 노트
- 라커룸 토크
- 이벤트
- 유료상품 공지
- 시장 정책 변경
- 사고 대응
- 보상

PoC 초기에는 자동 파서를 만들지 않는다.
사람이 주요 사건을 입력하고 source URL과 시간을 기록한다.

## 웹 상점

웹 상점에서 다음 정보를 확보한다.

- 판매 기간
- 가격
- 구매 제한
- 판매 채널
- 상품 구성
- 선수팩 조건
- 확률 정보
- 상대적인 인기 순위

공식 웹 상점은 인기순위 계산 방식을 판매금액 기준이라고 공개한다. 이를 판매량 자체로 환산하지 않는다.

## 멤버십

멤버십은 월별 반복 이벤트로 관리한다.
매월 1일 00:00부터 01:00까지 등급 산정이 진행된다.

## 제3자 서비스

다음 서비스는 참고·교차검증 용도로만 사용한다.

- `fifa-on.com`
- `bstpg.com`
- `fc-rank.com`
- `fc-info.com`

해당 서비스가 FC온라인 현재 시세와 유사한 값을 제공한다는 사실은 데이터 취득 가능성의 참고 사례다.
수집 방식과 데이터 사용권을 확인하지 않은 상태에서 해당 서비스의 데이터를 원본 데이터로 재배포하지 않는다.
