# 구현 순서

실제 작업 순서는 다음과 같이 고정한다.

1. **Gate 0**: 가격 데이터 확보 가능성과 이용 조건 검증
2. **Catalog**: 인기 선수와 클래스·강화단계 목록 생성
3. **Price history**: 과거 가격 시계열 적재
4. **Metadata**: 급여·능력치·팀컬러·특성 연결
5. **Events**: 과거 주요 공지와 상품 수동 annotation
6. **Relations**: 동일 선수와 팀컬러 대체재 관계 생성
7. **Market metrics**: 시장지수, breadth, dispersion 계산
8. **Cohort metrics**: 핵심군·고가군·직접 노출군 상대강도 계산
9. **Replay**: 라커룸 토크 11화와 SSS 사건 재생
10. **Shock**: 이상 변화 탐지
11. **Review**: 결과를 보고 분석 구조의 실질적 의미 평가

현재 첫 구현 목표는 1번이다.
가격 데이터 Gate가 통과되면 다음 구현은 "시장 전체 서비스"가 아니라 **대표 인기 선수군의 365일 데이터를 로컬에서 재생하는 작은 시장 연구 도구**로 시작한다.
