# 시장 선수군

PoC는 개별 카드 외에 cohort를 사용한다.

초기 cohort는 다음과 같다.

| Cohort                  | 의미                                         |
| ----------------------- | -------------------------------------------- |
| `MARKET`                | 선택한 대표 카드 전체                        |
| `CORE`                  | 장기간 실사용 수요가 높은 핵심 선수군        |
| `HIGH_END`              | 대표 표본 중 상위 가격대                     |
| `PREMIUM_SCARCE`        | 공급이 제한적이고 고가 수요가 있는 희소 카드 |
| `PACK_EXPOSED`          | 현재 상품·이벤트에서 직접 공급되는 카드      |
| `INDIRECT_EXPOSED`      | 직접 공급 카드의 주요 대체재                 |
| `META`                  | 랭커 사용량이 높은 카드                      |
| `FODDER`                | 강화 재료 성격이 강한 카드                   |
| `SAME_PLAYER`           | 동일 선수의 다른 클래스 묶음                 |
| `TEAM_COLOR_SUBSTITUTE` | 동일 팀컬러와 포지션에서 대체 가능한 카드    |

`CORE`를 "항상 우상향하는 선수"로 정의하지 않는다.
PoC 초기에는 호나우두, 굴리트, 해리 케인, 크리스티아누 호날두, 음바페, 지단, 비에이라 등 인기 실사용 선수를 사람이 seed한다.
향후에는 실제 사용량과 가격 데이터로 구성원을 재평가할 수 있다.
