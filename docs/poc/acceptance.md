# PoC 완료 기준

PoC는 다음 조건을 충족하면 1차 완료로 본다.

1. 대표 선수 20~30명의 주요 클래스와 강화단계를 식별한다
2. 허용된 방식으로 분석 가능한 과거 가격 데이터를 확보한다
3. 최소 6개월, 목표 365일 가격 시계열을 로컬 DB에서 조회한다
4. 가격과 player metadata를 연결한다
5. 동일 선수 클래스 관계를 조회한다
6. 팀컬러·포지션 기반 대체 후보를 조회한다
7. 랭커 사용 데이터를 일부 카드에 연결한다
8. 과거 주요 이벤트를 timeline에 등록한다
9. `MARKET`, `CORE`, `PACK_EXPOSED`, `PREMIUM_SCARCE` 지수를 계산한다
10. market 대비 cohort 상대강도를 계산한다
11. breadth와 dispersion을 계산한다
12. 라커룸 토크 11화 전후 데이터를 재생한다
13. SSS 20코인 사건 전후 데이터를 재생한다
14. 기준가 규칙 변경을 regime marker로 반영한다
15. 모든 지표가 원본 source까지 추적된다
16. 데이터 부족 시 결과를 생성하지 않는다

PoC 완료는 "서비스가 가치 있다"는 뜻이 아니다.
PoC 완료는 "데이터와 분석 구조가 실제 시장 사건을 재구성할 수 있다"는 뜻이다.
