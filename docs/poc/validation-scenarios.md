# PoC 검증 포인트

PoC는 알려진 사례를 replay해 분석 구조가 작동하는지 확인한다.

## PoC-01 동일 선수 클래스 간 관계

### 질문

`한 선수의 특정 클래스 가격이 크게 변할 때 다른 클래스에도 변화가 나타나는가.`

### 관측값

- 가격차
- 급여차
- OVR차
- 주요 스탯차
- 사용량
- 상대강도

호나우두처럼 여러 고가 클래스가 거래되는 선수가 적합하다.

## PoC-02 팀컬러 내 대체관계

### 질문

`특정 카드의 가치가 바뀌면 같은 팀컬러·포지션의 대체 카드가 반응하는가.`

예를 들어 레알 마드리드 ST 선수군을 하나의 작은 시장으로 본다.

## PoC-03 급여 차이

### 질문

`성능이 비슷한 카드에서 급여 차이가 가격·실사용량과 어떤 관계를 보이는가.`

급여 자체에 임의 가중치를 부여하지 않는다.
실제 채택 데이터를 함께 본다.

## PoC-04 선수팩 직접 공급

### 질문

`특정 클래스와 강화단계를 직접 공급한 상품 전후로 해당 cohort가 시장 대비 다르게 움직였는가.`

비교 대상은 가능한 범위에서 비슷한 조건을 가진 비노출 선수군으로 구성한다.

## PoC-05 동일 선수팩 내부 가치 차이

### 질문

`같은 공급 조건에 포함된 카드라도 실사용성에 따라 시장 반응이 다른가.`

### 비교 요소

- 실제 랭커 사용량
- 급여
- 팀컬러
- 대체재 수
- 포지션
- 동일 선수의 다른 클래스
- 공급 노출 여부

이는 "동일 OVR이면 동일 공급 충격"이라는 가설을 검증한다.

## PoC-06 월초·월말 패턴

### 질문

`실제로 월초와 월말 사이에 반복 가능한 가격 패턴이 존재하는가.`

월 자체만 분석하지 않는다.
같은 기간의 멤버십, 상품, 이벤트를 같이 표시한다.
목표는 다음 두 설명을 구분하는 것이다.

- 월초라서 시장이 움직였다
- 월초에 반복 배치되는 멤버십·상품·이벤트가 시장을 움직였다

## PoC-07 화요일 공지와 목요일 적용

### 질문

`공지 시점과 적용 시점 중 언제 가격 반응이 나타나는가.`

`announced_at`과 `effective_at`을 분리한 이유를 검증한다.

## PoC-08 라커룸 토크 11화

2026년 9월 28일 공지는 게임플레이와 특성 관련 변경을 포함했다.
사용자가 관찰한 시장 반응은 아직 검증된 결과로 기록하지 않는다.
PoC가 실제 가격 데이터를 통해 다음을 확인한다.

- 영향을 받은 특성 관련 선수
- 비관련 비교군
- 동일 선수 다른 클래스
- 발표 직후 변화
- 전체 시장 변화
- 상대강도 차이

## PoC-09 SSS 20코인 사건

이 사건은 비정기 충격을 처리하는 대표 검증 사례다.
공식 공지는 구매 제한 미설정과 높은 고가 선수 등장 빈도로 인해 단시간에 고가치 선수가 대량 공급됐다고 설명한다.
분석 timeline은 최소 다음 사건으로 나눈다.

1. 상품 공개
2. 비정상 공급 발생
3. 판매 임시 중단
4. 구매 제한 수정
5. 상품 조기 종료
6. 대응 공지
7. 피해 보상 발표
8. 실제 보상 지급

사용자가 관찰한 "ICON THE MOMENT 8강 등 비노출 희소 카드 수요 증가"는 검증 가설로 저장한다.
검증 대상은 다음과 같다.

- 직접 공급 대상군
- 비노출 일반 고가군
- 희소 프리미엄군
- 핵심 실사용군
- ICON THE MOMENT 고강군
- 동일 선수 다른 클래스

PoC가 확인할 것은 "3배 상승을 예측할 수 있었는가"가 아니다.
확인할 것은 `직접 공급 충격 이후 시장 내부의 상대강도와 희소성 프리미엄이 실제로 재배분됐는가.`이다.
