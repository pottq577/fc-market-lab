# FC온라인 이적시장 인텔리전스 PoC는 무엇을 검증하는가

이 문서는 제품의 문제, 사용자 작업, 출력 계약, 비목표를 정의한다.
구현 세부사항보다 어떤 질문에 답해야 하는지를 먼저 고정한다.

문서 계획: [문서 인덱스의 공통 계획](../00_INDEX.md#문서-계획)

## 제품 목표

PoC는 FC온라인 이적시장을 제한된 표본으로 재구성하고, 가격과 운영 사건을 하나의 시간축에서 설명할 수 있는지 검증한다.
미래 가격 예측, 구매 추천, 서비스 사업성 평가는 현재 범위에 포함하지 않는다.

초기 사용자는 개발자 본인 한 명이다.
사용자는 FC온라인 시장 경험은 있지만 통계 모델이나 Python을 전제로 하지 않는다.

## 제품이 답할 질문

제품은 개별 카드의 가격 조회보다 시장 구조를 설명하는 데 집중한다:

1. 선택한 대표 표본의 시장 상태는 어떻게 변했는가
2. 어떤 가격대와 선수군이 표본의 움직임을 주도했는가
3. 공지, 업데이트, 상품, 이벤트, 보상 같은 외부 사건과 가격 변화가 시간상 어떻게 겹쳤는가
4. 상품이나 이벤트에 직접 노출된 카드와 비노출 카드의 반응이 달랐는가
5. 동일 선수의 다른 클래스와 팀컬러 대체재가 어떻게 반응했는가
6. 실사용량, 급여, 능력치, 희소성 차이가 같은 공급 충격에서 다른 반응과 함께 관측되는가
7. 평상시 분포를 벗어난 변화가 발생했는가
8. 기준가 산정 규칙처럼 가격의 생성 구조가 바뀐 시점이 있는가
9. 현재 관측이 과거 사건과 어떤 구조적 공통점을 가지는가

`SAMPLE_MARKET`은 FC온라인 전체 이적시장을 뜻하지 않는다.
PoC에서 고정한 20–30명 선수 표본을 대표하는 지표다.

## 분석 관점

PoC는 외부 사건과 카드 내부 특성을 분리한다.
분석 경로는 다음 흐름을 기본 가설로 사용한다.

```text
외부 사건
  -> 직접 노출 instrument
  -> 동일 선수와 대체재 관계
  -> cohort 간 상대 변화
  -> SAMPLE_MARKET 내부 분산과 breadth 변화
```

이 흐름은 인과관계를 전제하지 않는다.
분석 결과는 시간적 동시성, 상대 차이, 과거 분포 이탈을 관측한다.

## 핵심 사용자 작업

제품은 세 가지 작업을 지원한다.

### 특정 날짜의 표본 시장을 확인한다

사용자는 다음 값을 함께 확인한다:

- `SAMPLE_MARKET` 변화율
- `CORE`, `HIGH_END`, `PREMIUM_SCARCE` 같은 cohort 변화율
- 상승 aggregation unit 비율인 `breadth`
- cohort 내부 또는 cohort 간 분산
- 활성 이벤트와 상품
- 직접 공급 노출군과 간접 노출군
- `SAMPLE_MARKET` 대비 상대강도

### 사건 전후를 재생한다

사용자는 사건의 공지 시점과 실제 적용 시점을 분리해 본다.
사건 replay는 다음 자료를 같은 시간축에서 비교한다:

- 사건 전후 가격
- `announced_at`, `effective_at`, `ended_at`
- 후속 공지와 보상
- 직접 공급 instrument
- 비노출 비교군
- 동일 선수의 다른 클래스
- 팀컬러와 포지션 대체 후보
- 당시 시점까지 관측된 랭커 사용 데이터

Replay는 분석 cutoff 이후에 관측된 cohort membership, 관계 snapshot, 사용 데이터를 사용하지 않는다.

### 선수 관계를 확인한다

특정 instrument를 선택하면 다음 관계 feature를 가격 변화와 함께 확인한다:

- 동일 실존 선수 여부
- 주요 포지션 일치 여부
- 공유 팀컬러
- 급여 차이
- Overall Rating (OVR) 차이
- 주요 능력치 거리
- 가격 비율
- 랭커 사용량 차이

PoC는 이 feature를 하나의 대체 가능성 점수로 합치지 않는다.

## 출력 계약

결과는 사실, 계산, 해석, 가설을 분리한다. 각 결과는 원본 snapshot과 `analysis_run`까지 역추적할 수 있어야 한다.

```markdown
## 사실

- 9월 17일 고가 선수 공급 관련 운영 공지가 확인됐다.

## 계산

- 직접 노출군 7일 수익률 중앙값: -18.4%
- SAMPLE_MARKET 7일 수익률 중앙값: +2.1%

## 해석

- 직접 노출군은 SAMPLE_MARKET보다 20.5%p 낮았다.

## 가설

- 공급 충격이 관측 차이를 설명하는 후보 요인이다.
```

가설을 사실로 승격하지 않는다.
상관관계와 사건 전후 차이를 인과관계로 표현하지 않는다.

## 제품 원칙

PoC는 다음 원칙을 유지한다:

- 개별 가격보다 표본 시장과 cohort 비교를 우선한다
- 단일 `MarketScore`를 만들지 않고 독립 신호를 유지한다
- 동일 선수의 다른 클래스와 대체재 관계를 핵심 데이터로 취급한다
- 임의의 실성능 가중합보다 실제 랭커 사용과 경기 기록을 보조 신호로 사용한다
- Shock와 Regime을 정상 시장 변동과 분리한다
- 생성형 인공지능 모델 없이 핵심 분석을 재현할 수 있게 한다
- Python을 필수 런타임으로 두지 않는다
- 모든 데이터와 파생 결과에 provenance를 보존한다

## 비목표

PoC는 다음 기능을 구현하지 않는다:

- 특정 카드의 목표가격 산출
- 구매 또는 매도 추천
- 3일, 7일, 30일 뒤 가격 예측
- 모든 FC온라인 카드의 전수 수집
- 실시간 공개 서비스 배포
- 서버리스 또는 클라우드 운영비 최적화
- 서비스 수익성 또는 시장성 판정
- 자동 공지 자연어 분류

PoC 완료 기준은 제품 가치의 결론이 아니다.
완료는 데이터와 분석 구조가 과거 사건을 재현할 수 있다는 의미다.
