# FC온라인 이적시장 인텔리전스를 로컬 PoC로 어떻게 검증할 것인가

`meta.contentType: Reference`

이 문서는 FC온라인 이적시장을 시장 단위로 관측하는 로컬 PoC을 정의한다.
목표는 미래 가격을 맞히는 것이 아니다.
가격, 게임 운영, 상품, 이벤트, 선수 성능, 팀컬러, 대체재 관계를 하나의 시간축에 결합해 현재와 과거 시장을 구조적으로 해석할 수 있는 기반을 검증한다.

## 문서 계획

이 문서는 구현 전 기준점을 하나로 고정한다.

- **목표**: FC온라인 시장 데이터를 재구성하고 설명 가능한 시장 인사이트를 산출하는 로컬 PoC를 정의한다
- **대상**: 초기 개발자 본인
- **범위**: 요구사항 정의, Product Requirements Document (PRD), Architecture Decision Record (ADR), 데이터 모델, 수집 전략, 분석 방법, PoC 검증 시나리오
- **제외**: 서비스 운영비, 수익화, 실제 사용자 확보, 배포 인프라, 투자·구매 추천, 가격 예측 정확도 평가
- **핵심 미해결점**: 365일 가격 시계열을 이용 조건에 맞는 기계 처리 방식으로 확보할 수 있는가

## 제품 정의

제품은 FC온라인의 개별 선수 가격 조회기가 아니다.
제품은 다음 질문에 답하는 시장 인텔리전스 도구다.

1. 현재 전체 이적시장은 어떤 상태인가
2. 어느 가격대와 선수군이 시장 움직임을 주도하는가
3. 현재 어떤 외부 변수가 시장에 작용하고 있는가
4. 특정 상품이나 이벤트에 직접 노출된 선수군은 어떻게 반응했는가
5. 직접 노출되지 않은 대체재와 희소 자산은 어떻게 반응했는가
6. 동일 선수의 다른 클래스 간 가격과 효율 관계는 어떻게 변했는가
7. 특정 팀컬러 안에서 대체 가능한 선수들은 어떻게 움직였는가
8. 현재 상황은 과거 어떤 사건과 구조적으로 유사한가
9. 평상시 범위를 벗어난 시장 변화가 발생했는가
10. 시장 구조 자체가 이전과 달라졌는가

제품은 관측값과 과거 데이터를 기반으로 설명한다.
"7일 뒤 호나우두가 300조가 된다" 같은 가격 예측은 핵심 기능이 아니다.

## 문제 정의

FC온라인 이적시장 가격은 단일 변수로 설명할 수 없다.
외부에서는 넥슨이 다음 요소를 지속적으로 바꾼다.

- 점검과 업데이트
- 화요일 전후의 점검·업데이트 사전 공지
- 목요일 정기점검
- 신규 클래스
- 선수 특성 변경
- 게임 이벤트
- 버닝 이벤트
- 유료 상품
- 선수팩
- BP 지급
- 멤버십
- 수수료 정책
- 기준가 산정 규칙
- 운영상 사고와 후속 보상

내부에서는 각 선수 카드의 시장 가치가 서로 연결된다.

- 동일 선수의 다른 클래스
- 능력치 차이
- 급여 차이
- 포지션
- 특성
- 약발과 신체 조건
- 소속팀과 국가
- 팀컬러
- 동일 팀컬러 내 대체재
- 실제 상위 랭커 사용량
- 실사용 경기 기록
- 가격대
- 희소성
- 강화 단계

따라서 `이벤트 → 개별 선수 가격`이라는 일대일 구조로는 시장을 설명하기 어렵다.
PoC는 `외부 사건 → 직접 노출 카드 → 대체관계 → 선수군 간 자금 재배분 → 전체 시장 상태 변화`의 구조를 전제로 한다.

## 제품 목표

PoC는 과거 365일 시장을 제한된 대표 선수군으로 재구성한다.
최종적으로 다음 출력을 재현할 수 있어야 한다.

```text
시장 상태
전체 시장        +4.2%
핵심 선수군      +8.1%
고가 희소군     +13.4%
상품 직접 노출군 -6.7%

상승 종목 비율    68%
시장 분산도       평소 대비 높음

활성 변수
- 멤버십 초기화
- BP 지급 이벤트
- 특정 클래스 선수팩 판매
- 수수료 이벤트

관측
- 전체 상승분보다 고가 희소 선수군의 상대강도가 높음
- 상품 직접 노출 선수군은 시장보다 약함
- 직접 노출군의 대체 선수군에서 상대강도 상승 관측
```

이 출력은 미래 가격을 단정하지 않는다.

## 비목표

PoC는 다음 기능을 구현하지 않는다.

- 특정 카드의 목표가격 산출
- "지금 사라", "지금 팔아라" 같은 구매·매도 추천
- 3일·7일·30일 뒤 정확한 가격 예측
- 거대한 단일 `MarketScore` 산출
- 생성형 인공지능 모델의 자체 시장 판단
- 모든 FC온라인 선수 수집
- 실시간 서비스 배포
- Vercel, Supabase 등 운영 인프라 설계
- 서비스 수익성이나 시장성 판정

PoC 완료 후 별도 단계에서 판단한다.
